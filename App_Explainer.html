App Explainer & Testing Guide

This document explains how to evaluate the Necrotizing Fasciitis Mortality Predictor mobile application.

Repository: https://github.com/jpg123/NF-mortality-calculator

Device Compatibility: The application is built as a responsive HTML tool. You can open NF-mortality-calculator.html locally on your desktop computer or transfer the file to run directly within the web browser native to your mobile phone (iOS/Android). In addition, you can toggle between Dark Mode and Light Mode using the selector in the upper right-hand corner of the app interface.

How to Use the App

  1. Access the App: Open the NF-mortality-calculator.html file provided in this folder.
  2. Review Clinical Disclaimer: Read and acknowledge that the tool is an investigational prognostic calculator using locally stored model coefficients.
  3. Data Entry: The app is configured exactly as a physician might interact with it during triage. The inputs are natively blank. Populate the laboratory fields and clinical checklists according to the sample cases below.
  4. Processing & Output: Upon pressing "Calculate Risk," local calculations trigger. You will see a probability output and the implemented model component contributions.

How the component display works

A predictive algorithm traditionally operates as a "black box": it outputs a percentage but provides zero context as to why. In clinical fields like surgery, black box recommendations are often ignored because doctors cannot rapidly trust reasoning they cannot biologically translate.

The calculator displays the relative contributions of the implemented model components. These are descriptive outputs of the coefficient-based research implementation and should not be interpreted as causal effects.

Visualizing the Tug-of-War

  • The Baseline: Every patient starts at a mathematical baseline risk representing the "average" patient across a 21-year registry.
  • Positive contributions: Components with positive coefficients increase the calculated log-odds in this implementation.
  • Negative contributions: Components with negative coefficients decrease the calculated log-odds in this implementation.
