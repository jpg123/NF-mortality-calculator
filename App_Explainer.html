App Explainer & Testing Guide

This document describes the NF mortality research calculator, its inputs, and the limits of its displayed estimates.

Repository: https://github.com/jpg123/NF-mortality-calculator

Device Compatibility: The application is a responsive HTML tool. Open index.html in a modern desktop or mobile browser. The calculator is investigational and is intended for research and educational use, not diagnosis or treatment decisions.

How to Use the App

  1. Access the App: Open the NF-mortality-calculator.html file provided in this folder.
  2. Review Clinical Disclaimer: Read and acknowledge that the tool is an investigational prognostic calculator using locally stored model coefficients.
  3. Data Entry: The inputs are blank when opened. Enter the requested demographic, laboratory, comorbidity, presentation, and acute-care fields. “Blood products received” is the user-facing label for the binary model input; the internal model identifier remains transfusion.
  4. Processing & Output: Upon pressing "Calculate Risk," local calculations trigger. You will see a probability output and the implemented model component contributions.

How the component display works

The calculator reports an estimated in-hospital mortality probability and displays the implemented coefficient contributions for the entered characteristics. Its output is a research estimate and should not direct individual care.

The calculator displays the relative contributions of the implemented model components. These are descriptive outputs of the coefficient-based research implementation and should not be interpreted as causal effects.

Visualizing the Tug-of-War

  • Intercept: The fitted model intercept supplies the starting log-odds before the entered characteristics are added.
  • Positive contributions: Components with positive coefficients increase the calculated log-odds in this implementation.
  • Negative contributions: Components with negative coefficients decrease the calculated log-odds in this implementation.
